## Find saved work

Choose **Find & commands** in the header. Outside editable fields, Ctrl+K (Linux/Windows) or Cmd+K (macOS) opens it. Inside the editor use the header button so the editor keeps its keys. Type title, passage, checklist or label words; all words must match. Filter by label or include Archive; Trash is excluded. At most twenty results appear.

Arrows/Enter choose, Tab reaches filters and Escape restores focus. Opening a note focuses its title. Links/backlinks and **Back to notes** continue navigation. Ctrl/Cmd+S saves inside the editor; failure retains the draft.

## Capture safely

With no phrase, choose **New blank note**, **New source note** or **New decision note**. Templates provide editable prompts, not generated claims. A nonempty draft is focused rather than replaced. Unsaved-work confirmation remains active.

Search matches bounded literal text within the signed-in account. It uses no embeddings/inference service. Failure preserves the phrase/filters for Retry. Hosted acceptance exercised search, archive/labels, capture/save, dirty drafts, links and anonymous refusal. Chromium checks also exercised keyboard, network retry and scoped accessibility.
