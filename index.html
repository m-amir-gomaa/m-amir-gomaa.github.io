01 / BROWSER APPLICATIONJavaScript · CSS · Webpack · LocalStorage

Local Keep — Browser Notes & Checklists

A local Google Keep clone built directly with native DOM APIs. Create notes and checklists, organize with labels and colors, search instantly, and export/import portable JSON backups.

Read the manual →Implementation notes →Build history →
The engineering behind it +

The problem

Quick notes should work immediately without an account or server. Browser storage is convenient, but users still need reliable backup, validated import, and safe recovery if storage writes fail.

What I built

  • Modular vanilla JavaScript and native DOM events without a UI framework.
  • Notes, checklists, pinning, color themes, labels, search, archive, and recoverable trash.
  • Versioned JSON backup/export including archived and trashed items.
  • Validated, additive JSON import with duplicate protection and storage-failure rollback.
  • Raw JSON recovery path when existing browser data is malformed, instead of silently resetting user notes.

What I check

Store operations, checklist editing, backup roundtrips, malformed imports, duplicate IDs, partial storage failures, and responsive keyboard navigation.

The embedded demo uses this browser's localStorage. Your notes stay on this device.

02 / SYSTEMS & TOOLINGNixOS · Home Manager · Hyprland · Neovim

NixOSenv — Reproducible Development Workbench

A flake-pinned NixOS workstation combining a keyboard-first Hyprland Wayland desktop, wrapped Neovim with Nix-supplied language servers, explicit security hardening, and verified recovery workflows.

Open interactive workbench →System architecture →Neovim workflow →Build & verify →
The engineering behind it +

The problem

Development machines drift over time as global packages, editor binaries, and desktop settings accumulate ad-hoc edits. Rebuilding cleanly should be predictable without risking personal data or secrets.

What I built

  • Flake-pinned NixOS + Home Manager configuration separating declarative packages from mutable personal state.
  • Hyprland Wayland desktop with Kitty, Waybar, Rofi, PipeWire/WirePlumber, and explicit Intel-default / NVIDIA-offload graphics.
  • Nix-wrapped Neovim supplying gopls, typescript-language-server, nil, pyright, clangd, rust-analyzer, Marksman, and formatters natively.
  • Stateful firewall, restricted local DNS, root-editor isolation, source-hygiene build checks, and automated backup verification.

What I check

Full flake evaluation and system builds, Home Manager activation, headless Neovim language-server resolution, Hyprland config validation, and disposable-data backup copy tests.
