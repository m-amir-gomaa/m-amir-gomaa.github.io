# Portfolio workspace instructions

This repository is the static GitHub Pages source for `amirgomaa.com`.

- Keep the site strictly contact-free (outbound owner contact is Upwork only; no direct email, phone, LinkedIn, or GitHub profile contact links, and no `<form>` elements).
- Keep the public portfolio focused on **NixOSenv** and **Local Keep** (plus brief links/descriptions for future standalone products only when explicitly authorized after launch; standalone products maintain their own domains and Hugo blogs).
- Rebuild `manuals/` with `python3 scripts/build-docs.py` and verify with `python3 scripts/build-docs.py --check && python3 scripts/check-docs.py`.
