Third-party source notes

Verified 14 October 2026. The extraction worker installs the official PyPI release mineru[pipeline]==2.7.6 and invokes its CLI without patching it. Official source release: mineru-2.7.6-released , commit e31c0ec34da89f6d7db78866ffec13eb0aaa3a3c. That release’s LICENSE.md is GNU Affero General Public License version 3. Current master licensing must not be substituted for the pinned release’s terms.

MinerU attribution and the exact upstream source link are visible in the UI and README. Pageweft’s application source is maintained in its existing repository; anonymous GitHub access returned 404 on 19 October 2026, so public availability is not claimed. The official pinned MinerU source remains linked directly. This note does not relicense the owner’s wrapper or certify that subprocess separation resolves every license boundary. Any engine/model changes need their own exact-release source and license review. A complete transitive dependency/model license inventory has not been produced; package version pinning alone does not establish it.

Owner inspection of the actual deployed model-cache volume on 14 October 2026 found opendatalab/PDF-Extract-Kit-1.0, snapshot ed6b654c018d742e65a17671e379c5e6ecc87ec9. The model card at that exact cached revision was fetched successfully and declares AGPL-3.0. No new weights were downloaded to perform this inspection. Repository-level licensing and an observed cache revision do not certify every bundled model/dependency or force future remote fetches to remain pinned; that inventory and reproducibility check remain in the launch register.
