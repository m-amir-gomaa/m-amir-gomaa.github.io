Using the vanilla demo

Understand the separate browser-only demonstration and its storage boundary.

16 October 20261 min readDownload Markdown ↓

Open the portfolio demo

Open the bundled demo or launch it from the portfolio’s vanilla JavaScript card. This is a separate implementation from Noteweld. It demonstrates native browser APIs rather than the professional Next.js application.

Work in one browser

Try notes and checklists, pin/color/label controls, archive and trash. Storage belongs to this browser and website origin. It does not create a cloud account, synchronize devices or inherit Noteweld’s editor/graph features.

Use a disposable test note when exploring the demo. Browser data clearing, private browsing, storage limits or a different origin can affect persistence. Keep important content outside a portfolio demonstration.

Source versus published bundle

The source notes describe the current local implementation, including JSON backup/import work and known controls needing further release review. That source can be ahead of the copied portfolio bundle. Do not assume every local capability is present in the embedded demo.

Current local limitations include an unfinished header search, placeholder reminders and further storage-failure/accessibility review. Use the notes-view search where available. A future parity release will be separate from the professional Noteweld releases.
