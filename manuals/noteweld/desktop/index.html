Local files and your real editor

The source-distributed unsigned Linux x64 alpha opens an ordinary Markdown/Obsidian folder. No account is needed for offline reading, full-text search, links/backlinks, Connections, note templates and supported local media. Refresh files updates indexes after another app edits files. Start with a copy of valuable work and keep independent backups.

Edit in nvim opens the actual editor in a split pane; Expand editor enlarges the same process. Use :w to save and :wq to save/close. Ctrl/Cmd+Shift+F6 returns focus to app controls. Settings accepts an executable plus separate arguments, not a shell command string. Neovim uses its normal configuration/plugins and local-user permissions beyond the renderer sandbox.

A checked working copy protects the original; written edits are verified before replacement. Concurrent edits preserve both, and written work can recover after restart. Unwritten keystrokes are not recoverable. Remote images are not automatically loaded and the viewer does not run Obsidian plugins.

Preferences, setup and limits

Optional cloud sync requires browser approval and exact transfer confirmation. Credentials stay outside the vault in private files, not an encrypted keychain. Six palettes, light/dark/system, reading font/size and 32 app color roles save locally; Neovim colors/keymaps remain its own settings.

The owner-access source contains Node 24, native dependency, runtime/build and launch instructions. This page does not distribute an installer/private source. Thirteen actual Linux scenarios, packaged SQLite/PTY/Neovim, written restart recovery, scoped accessibility and hosted two-way sync/revocation passed. Independent finish review accepted the two listed corrections. macOS/Windows packages, signing, auto-update and every editor plugin remain unqualified.
