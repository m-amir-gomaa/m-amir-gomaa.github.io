Inspect the work

The public portfolio combines working applications, implementation manuals, release records and deliberately selected source examples. Production source access is reserved for owner-authorized review. This describes the publication policy; it is not proof of a repository’s current GitHub visibility setting.

It demonstrates a specific engineering boundary: original machine recognition, user corrections and advisory AI notes remain distinct. The manifest checks byte integrity, not factual correctness or authenticity.

Production review and dependency obligations

For a focused source walkthrough, contact Mohamed with the area you want to inspect. Authorized review can cover the relevant implementation and test evidence without exposing unrelated private data or provider credentials. Public documents retain source revisions even when their original source and CI records need repository access. A dated CI result is recorded evidence, not a claim that its log remains anonymously accessible.

Sonaweft’s MIT baseline and any previously distributed copies keep their permissions. Pageweft invokes the unmodified pinned MinerU CLI, but process separation alone is not a licensing clearance. The exact engine/model terms and remaining review are in Pageweft dependencies . No proprietary notice overrides applicable source-disclosure obligations.

The portfolio, Fieldnotes, Noteweld Local and this selected sample remain public. The sample’s MIT license applies to its directory; it does not license every website asset or unrelated application.

Browsers still receive the HTML, CSS and JavaScript used by a web interface. Private repository access protects the full source tree and private server implementation; it cannot make delivered frontend code invisible. Provider credentials and access-control decisions must stay on the server.
